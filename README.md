## Server App for Backend

### Config Application

1. Yaml

   ```yaml
   spring:
     application:
       name: serverapp
   ```

2. Properties

   ```properties
   spring.application.name = serverapp
   ```

3. XML

   ```xml
   <spring>
      <application>
        <name>serverapp</name>
      </application>
    </spring>
   ```

4. Json
   ```json
   {
      spring : {
        application : {
          name: serverapp
          }
        }
    }
   ```
